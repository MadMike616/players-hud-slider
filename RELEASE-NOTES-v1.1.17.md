# Players HUD Slider v1.1.17

- Removes the exact-byte native signature check that previously blocked plugin startup.
- Keeps the existing native addresses and player-count patch location.
- Does not add automatic support for other D2R layouts.

## Compatibility

- D2RLoader ABI 4
- Addresses remain based on the D2R 3.3.93847 reference layout
- Install the DLL in `mods/GrailerRL/d2rloader/plugins/`.
