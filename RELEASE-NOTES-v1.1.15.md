# Players HUD Slider v1.1.15

- Includes the HUD button with normal, hover, pressed, and disabled sprite states.
- Aligns the state sprites so the icon stays steady during hover and click transitions.
- Includes custom PNG artwork, generated native sprites, and the TOML config template.

## Compatibility

- D2RLoader ABI 4
- D2R 3.3.93847 reference layout
- Install the DLL in `mods/GrailerRL/d2rloader/plugins/`.
